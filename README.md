# Dynamic Pricing Prediction for Ride Booking Service

## About the Project
This project predicts ride prices using Python and Machine Learning.

## Objectives
- Analyze ride booking data.
- Clean and prepare the dataset.
- Predict ride prices using Machine Learning.
- Compare different ML models.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Linear Regression
- Decision Tree
- Random Forest

## Project Results
The models were evaluated using:
- MAE
- RMSE
- R2 Score

## Conclusion
This project helps predict ride prices based on different ride-related factors using Machine Learning.
